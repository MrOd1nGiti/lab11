# Лабораторная работа 11. JSON и получение данных по HTTP

Выполнил: Вариант 1 (Все задачи пользователя)

## Описание программ

- `analysis.py` - модуль для валидации структуры JSON-данных (`validate_todos`), расчета статистики завершенных задач (`completion_counts`), поиска лидеров (`top_users`) и фильтрации задач по пользователю (`select_tasks`).
- `main.py` - главная программа с защищенным вводом, чтением и валидацией `todos.json`, вычислением и сохранением результатов в файлы `leaders.json` и `selected.json`.
- `test_analysis.py` - набор автоматических тестов для проверки логики анализа и строгой типизации полей.
- `todos.json` - входной файл данных.
- `leaders.json` и `selected.json` - выходные файлы с результатами обработки.
